# Carvizo Implementation Plan
> **For agentic workers:** Tasks ordered by dependency; each task has focused tests and verifications.
**Goal:** Livrer la PWA Carvizo utilisable pour un automobiliste.
**Architecture:** Next.js App Router sur MariaDB ; API privées par session ; calculs de domaine découplés ; worker cron de notifications.
**Tech Stack:** Next.js 16, React 19, Prisma 7, MariaDB 11.4, Web Push.
**Spec:** docs/specs/2026-11-13-carvizo.md
## Global Constraints
- Langue V1 : français ; PWA responsive.
- Gratuit sans publicité ; comptes cloud obligatoires.
- Plusieurs véhicules, gestion flottes collaborative progressive.
- Photos privées ; entretiens, consommation, dépenses, dégâts, pannes et pneus.
## Review Focus
- Kilométrage décroissant : rejeter le compteur antidaté par rapport à la valeur actuelle.
- Volume nul au plein : refuser calcul.
- Chevauchement des rapports d'entretien : aucun rappel dédoublé.
- Accès aux données d'un autre compte : 404.
- Mauvais format de photo : 415.
