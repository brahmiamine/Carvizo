# Identité visuelle Carvizo

Identité sélectionnée : **proposition 1**, lettre C bleu nuit, route turquoise et silhouette automobile. Le fichier source raster proposé est représenté par une version vectorisée fidèle pour conserver des contours nets à toutes les résolutions.

- `public/logo.svg` : logo complet (symbole + nom vectorisé).
- `public/brand-icon.svg` : symbole seul, pour la navigation et le favicon SVG.
- `src/lib/brand-shapes.ts` : source des silhouettes partagées.
- `src/components/brand-mark.tsx` : symbole utilisé par les images générées.
- `src/app/icon.tsx` : icône PNG 512×512 pour PWA / Android / favicon.
- `src/app/icon-192/route.tsx` : icône PNG 192×192.
- `src/app/apple-icon.tsx` : icône PNG 180×180 pour iOS.
- `src/app/splash/route.tsx` et `public/splash.svg` : écran de lancement.
- `src/app/badge/route.tsx` et `public/notification.svg` : pictogramme blanc monochrome de notification.

Palette : bleu nuit `#032758`, turquoise `#04BAA9`, fond sombre `#0B1928`. Les photos enregistrées par les utilisateurs ne sont pas des éléments de marque et ne sont pas modifiées.
